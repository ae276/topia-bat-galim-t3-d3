# TOPIA בת גלים · T3 · דגם D3

הדמיה תלת־ממדית אינטראקטיבית של דירת 4 חדרים, דגם D3 במגדל T3 (מתחם TOPIA, בת גלים, חיפה):
חתך אקסונומטרי, סיור בגוף ראשון, המגדל בהקשר, חניון המתחם (מרתפים 1- ו־2-), הנוף מהמרפסת בקומה 23,
ומפרט המכר חדר־חדר. האתר מתאים את עצמו למחשב, לטאבלט ולנייד.

- המודל שורטט מתוכניות המכר ומגיליונות הקומות (1:50, 1:100, 1:200). התוכניות, ההדמיות והמפרט שייכים ליזם ולמשרד האדריכלים; הם מוצגים כאן להמחשה בלבד ואינם מסמך מחייב.
- גובה קומה (3.20 מ׳), קומת קרקע (5.0 מ׳) וגובה המרתף הם הנחות, אין חתך בסט.
- הריהוט, המכוניות ומיקומי נקודות החשמל להמחשה בלבד.
- תמונות הנוף מהמרפסת: ‎© Google Earth (צילום מ־24.3.2025), עם שכבות הבנייה המתוכננת שנוספו מעליהן.
- מנוע תלת־ממדי: three.js, three-mesh-bvh, three-gpu-pathtracer (רישיון MIT).

האתר סטטי לחלוטין: `index.html` וקבצי העזר שלידו. אפשר להריץ אותו מכל שרת קבצים.
